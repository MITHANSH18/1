Structural Tags
These tags define the structure of the HTML document.
Semantic Tags
These tags provide meaning to the content they contain.
Text Formatting Tags
These tags are used to format text in various ways.
Inline Tags
These tags are used to format text inline within a paragraph.
List Tags
These tags are used to create ordered and unordered lists.
Image Tags
These tags are used to embed images in the document.
Table Tags
These tags are used to create tables in the document.
Form Tags
These tags are used to create forms for user input.
Media Tags
These tags are used to embed media content in the document.
Div Tags
These tags are used to group other HTML elements together.
Code and Pre Tags
These tags are used to display code and preformatted text.
Iframe Tags
These tags are used to embed another HTML document within the current document.
Footer Tags
These tags are used to define the footer section of the document.
Accessibility and SEO Tags
These tags are used to improve accessibility and search engine optimization.
